# Production concept vs. public demo

## Production concept

The internal project was a WordPress-based self-guided IT onboarding website. It used custom PHP, CSS and JavaScript to protect the site, route employees and guests into different flows, adapt the page order to device and workplace choices, and present real setup instructions for approved company services.

The production environment contained company branding, real screenshots and videos, internal URLs, support contacts and operational instructions.

## Public demo

This repository is an independent rewrite using fictional data and neutral branding. It preserves the engineering concepts and user journey while removing confidential or proprietary material.

The following are simulated or replaced:

- access is local and does not contact an identity provider;
- `demo123` opens the employee flow and `guest123` opens the guest flow;
- internal URLs and support contacts are replaced with explanatory placeholders;
- real screenshots and videos are replaced with neutral illustrations;
- password, MFA, QR, VPN and MDM steps are instructional only;
- office names and employee details are fictional;
- no production analytics or employee tracking is included.

## Code ownership

No production WordPress export, database, employer source code, credentials, internal certificate, media file or proprietary content is distributed in this repository.
